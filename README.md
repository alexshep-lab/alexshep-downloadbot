# AlexShepDownloadBot

Telegram-бот, который скачивает видео из YouTube (включая Shorts), Instagram (Reels, посты),
TikTok и X (бывший Twitter) и присылает их в чат. Работает на [aiogram 3](https://docs.aiogram.dev/) + [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Требования

- Python 3.11+ (проверено на 3.14)
- [ffmpeg](https://www.gyan.dev/ffmpeg/builds/) в PATH — нужен yt-dlp для склейки видео и звука
  (`winget install ffmpeg`)

## Установка

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и получи токен.
2. Скопируй `.env.example` в `.env` и впиши токен в `BOT_TOKEN`.
3. (Рекомендуется) Впиши свой Telegram id в `ALLOWED_USER_IDS`, чтобы ботом
   не пользовались посторонние. Свой id подскажет [@userinfobot](https://t.me/userinfobot).

## Запуск

```powershell
.venv\Scripts\python bot.py
```

или просто двойной клик по `run_bot.bat`.

Дальше — пришли боту ссылку на видео, он ответит файлом.

## Использование в группе

1. У [@BotFather](https://t.me/BotFather): `/mybots` → выбери бота → **Bot Settings** →
   **Group Privacy** → **Turn off**. Иначе бот не видит обычные сообщения в группах.
   Если бот уже был в группе — удали его из группы и добавь заново, только после
   этого настройка применится.
2. Добавь бота в группу и отправь там команду `/id` — бот покажет id чата
   (отрицательное число).
3. Впиши этот id в `ALLOWED_CHAT_IDS` в `.env` и перезапусти бота.

После этого бот будет скачивать видео по любой ссылке YouTube/Instagram,
появившейся в группе, а на остальные сообщения реагировать не будет.

## Cookies (если Instagram или YouTube требуют вход)

Instagram часто отдаёт видео только залогиненным, а YouTube на серверных IP пишет
«Sign in to confirm you're not a bot». Лечится файлом cookies:

1. Поставь в браузер расширение **Get cookies.txt LOCALLY** (Chrome/Firefox).
2. Залогинься на сайте (для Instagram лучше завести **отдельный** аккаунт —
   основной может словить ограничения за автоматизацию).
3. Экспортируй cookies в файл `cookies.txt` в папку бота.
4. В `.env` укажи `COOKIES_FILE=cookies.txt` и перезапусти бота.

Альтернатива одной командой (возьмёт cookies из установленного Chrome):

```powershell
.venv\Scripts\yt-dlp --cookies-from-browser chrome --cookies cookies.txt --skip-download https://www.instagram.com/
```

## Лимиты и как их обойти

- **50 МБ на файл** — лимит Telegram Bot API. Бот автоматически понижает качество
  (1080p → 720p → 480p → 360p), пока видео не влезет. Если не влезло даже в 360p —
  скажет об этом. Обход лимита до 2 ГБ — свой [локальный Bot API server](https://github.com/tdlib/telegram-bot-api)
  (можно добавить позже).
- **yt-dlp надо обновлять**: YouTube и Instagram регулярно меняют защиту.
  Если скачивание сломалось, первым делом:

  ```powershell
  .venv\Scripts\python -m pip install -U yt-dlp
  ```

## Настройки в .env

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ALLOWED_USER_IDS` | кто может пользоваться ботом, id через запятую; пусто = все |
| `ALLOWED_CHAT_IDS` | разрешённые группы (id отрицательный, узнать — /id в чате) |
| `COOKIES_FILE` | путь к cookies.txt для Instagram/YouTube |
| `COOKIES_SERVICES` | кому подставлять cookies: `ig,yt,tt,x` или `all` (по умолчанию `ig`) |
| `PROXY` | прокси для скачивания (`http://...`, `socks5://...`) |
| `ALLOW_ANY_SITE` | `true` = качать с любых сайтов, которые знает yt-dlp |
| `DOWNLOAD_DIR` | папка для временных файлов |
| `DOWNLOAD_TIMEOUT` | таймаут скачивания, сек (по умолчанию 900) |
| `UPLOAD_TIMEOUT` | таймаут отправки файла в Telegram, сек (по умолчанию 600) |
| `TELEGRAM_API_URL` | адрес локального Bot API server; пусто = облачный Telegram |
| `MAX_FILE_SIZE_MB` | лимит размера файла (50 облачный / до 2000 локальный) |
| `MAX_HEIGHT` | максимальное качество для коротких видео (1080) |
| `PREFERRED_HEIGHT` | качество для длинных и тяжёлых видео (720) |
| `HD_MAX_SIZE_MB` / `HD_MAX_DURATION_MIN` | пороги «тяжёлого»/«длинного» видео (100 МБ / 20 мин) |
| `PROGRESS_INTERVAL` | как часто обновлять статус скачивания, сек (5) |
| `CACHE_FILE` | где хранить file_id уже отправленных видео (`file_ids.json`) |
| `THROTTLE_FLOOR_KB` | порог «соединение придушили», КБ/с — ниже него берётся свежая ссылка (500) |
| `RATE_LIMIT_COOLDOWN_MIN` | пауза после HTTP 429, минут (30) |

## Ограничение по частоте (HTTP 429)

Instagram считает запросы без cookies анонимными и держит для них жёсткий суточный лимит.
Когда он исчерпан, приходит `HTTP 429: Too Many Requests`.

Бот в этом случае **перестаёт обращаться к сервису на `RATE_LIMIT_COOLDOWN_MIN` минут**
и отвечает, сколько осталось ждать: повторные попытки во время блокировки только
продлевают её. Пауза действует отдельно для Instagram и YouTube, а видео из кеша
продолжают отправляться как обычно.

Durable-решение — cookies (см. раздел выше): у залогиненного аккаунта лимиты
несравнимо выше. Для этого лучше завести отдельный аккаунт, не основной.

## Кнопки под сообщением

Пока идёт закачка, под статусом есть две кнопки:

- **🎵 Только звук** — бросить видео и забрать одну звуковую дорожку (mp3 192 kbps
  с названием, исполнителем и обложкой);
- **❌ Отменить** — прекратить закачку.

Под готовым файлом появляется **🗑 Удалить**.

Нажимать может тот, кто прислал ссылку, и владелец бота (те, кто указан
в `ALLOWED_USER_IDS`). Остальным бот отвечает, что кнопка не для них.

Удалять Telegram разрешает боту только свои сообщения и только первые 48 часов —
дальше кнопка выдаст предупреждение.

## Повторные ссылки

Одно видео скачивается только один раз:

- если ссылку прислали второй раз (в том числе в другом чате) — Telegram пересылает
  уже загруженный файл по `file_id`, мгновенно и без скачивания (вместе с названием);
- видео и звук одного ролика кешируются раздельно;
- если то же видео прислали, пока оно ещё качается — второй запрос ждёт на замке
  и получает результат первого, а не запускает параллельную загрузку
  (две параллельные загрузки одного видео YouTube жёстко душит).

Ссылки сравниваются по id видео, поэтому `?list=…`, `?si=…`, `&t=…` дублей не создают.
Кеш переживает перезапуск бота — лежит в `file_ids.json`.
| `MAX_CONCURRENT_DOWNLOADS` | сколько видео качать одновременно (по умолчанию 2) |
